# TWO MINUTES — prototype

One wall. One shared minute. Two minutes to break through it, scored, with the board
revealing after. Built as a single self-contained HTML file (no build step, no backend).

**This is a prototype for review.** The crowd, the leaderboard and the counts are
simulated in the browser — there are no real users, no accounts and no money in it yet.

## What it demonstrates
- **The loop:** strike the wall → the crack spreads → stop and it heals → combo builds.
- **The spike:** streak, live crowd, combo multiplier, the break, then the ranked reveal.
- **The shape that can be monetised without a licence:** the live counter is the sellable
  asset (brand slot beside it), consumable cosmetics, and private walls sold to companies.
  Nothing is redeemable, so nothing is stored value.

## Run it
Open `index.html` in a browser. For the walkthrough press **OPEN THE WALL NOW** —
in the prototype the wall also opens automatically every 5 minutes.
